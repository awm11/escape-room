TEMPORAEscape room: teacher guide

A physics escape room for Year 8. Groups are stranded on a freezing ship orbiting Mars and must work through puzzles to restart the engines, guided by Mars Base Alpha on the ship's terminal. The terminal is a web page, so all you need is a laptop with a browser. There is no login.

What you need

Per group, as well as the printed resources and a laptop:

  • Pendulum bob on a metre-long string with a loop
  • Stop clock
  • Tape
  • Various colour filters, including red
  • Compass, magnet and magnifying glass (these are decoys)
  • Clamp stand and clamp
  • An empty, dry kettle
  • Blu Tack
  • 8 zip ties
  • Two padlocks with settable codes, a box to use as the Orbital Utility Kit, and a lockable cupboard

Setting up

  1. On each laptop, open alexmoorephysics.com/escape-room. Plug it in and turn off sleep so the screen stays on. Full screen (F11, or Ctrl+Cmd+F on a Mac) looks best.
  2. Leave it on the start screen. Groups can type their crew names before pressing Start mission. The names appear on the mission report at the end.
  3. Stick the Captain's Code-le under the desk.
  4. Lock the black and white filter grid in the cupboard, with the Captain's Locker sign on the front.
  5. Put the manual (with the shopping list inside) on the desk.
  6. Optional: play some atmospheric music. Option 1 (recommended), option 2, option 3.
Students should not write on any of the sheets. If they need to, they can use a blank piece of paper.

Running the room

Mars Base Alpha tells students they have about 40 minutes. The cabin temperature in the corner of the screen drops the whole time, and frost creeps in from the edges, but nothing happens when it gets very cold. It's there for atmosphere.

  1. Do Now

    Students complete the Do Now. The first letters of the answers spell TEMPORA. When they show you, hand over the envelope with the story letter, and let them press Start mission.

  2. Repair the heating

    The ship's menu appears. Students choose an item with the arrow keys and Enter (or by tapping it). Choosing Heating shows the cabin is at 5°C and tells them to contact the Martian Citadel, so they choose Call Martian Citadel. Mars Base Alpha answers and explains the problem.

    Scenes 1–2

  3. Open the Orbital Utility Kit

    Students find the "shopping list" in the ship's manual. They solve it to get the 3-digit code 783, which opens the box.

  4. Solve the puzzle to find the kettle

    Students take the puzzle out of the envelope and fill in the grid to make an image, then go two down and three across to find the kettle on the reverse. Inside the kettle is a torn-out page. They type its phrase into the terminal:

    Time's tide waits for no one: set course for the future.

    It must be exact: capitals, spelling and punctuation all count. Quotation marks around it are fine either way, and so are the curly quotes iPads add.

    Scene 3

  5. Test the gravity

    Mars Base Alpha asks whether the gravity feels normal (any answer is fine), then asks for a measurement. Students follow the pendulum instructions in the manual: time 10 swings and divide by 10. The period should be about 2; anything from 1.9 to 2.1 is accepted. They type the number only, with no unit. If they type about 1, Alpha tells them they've counted each swing and should double it.

    Scenes 4–5

  6. Open the Captain's Locker

    Alpha reports back from Earth and says the access code is under the captain's desk. Students solve the Captain's Code-le to get 478 and open the cupboard to find the black and white grid.

    Scene 6

  7. Restart the engines

    Looking through the red filter (there's a hint on the bottom of the box) reveals the restart code on the grid. In the ship's menu students choose Engines, press Enter, then type 8643.

    Scenes 7–8

  8. Mission report

    The engines start, the cabin warms up, and Mars Base Alpha calls to congratulate them. A mission report then shows the crew names, time taken, number of wrong answers and the coldest the cabin got. It isn't saved anywhere, so take a photo of it or press Copy report.

If something goes wrong

  • The game doesn't time out. Groups can take as long as they need.
  • Page refreshed or closed by accident: reopen it and click Resume from step N on the start screen. The group restarts at the beginning of the scene they were on.
  • A group is stuck or you need to skip ahead: on the start screen, click sys admin in the bottom-right corner and choose a scene. You can also clear saved progress there.
  • Waiting for text to type out: pressing Enter while Mars Base Alpha is talking finishes the current message instantly.

Scenes in the sys admin menu

  1. Ship menus: call the Citadel
  2. Mars Base Alpha explains
  3. Secret phrase from the manual
  4. Gravity check
  5. Pendulum period
  6. Clearance from Earth
  7. Ship menus: engines
  8. Engine restart code
  9. Final call

Starting from a later scene begins colder, to match how far through the mission the group would be. The mission report notes that the run didn't start from the beginning.

Afterwards

Put everything back where it came from, using each group's kit as a checklist, and lock the padlocks again ready for the next class.
